Cigale is a quiet, sunlit landing hero inspired by the cicada’s song: translucent wings, fading ripples, and a few ember motes set against dusk. The project is intentionally dependency-free at runtime; `index.html` is the page, `css/styles.css` contains the visual system and motion, `js/hero.js` wires the effects and exports pure helpers, and `tests/hero.test.mjs` covers those helpers. Run `npm install`, `npm test`, and `npm run lint`; open `index.html` directly in a browser to view the page.
